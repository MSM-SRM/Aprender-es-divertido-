# Plantilla común de composición de los cromos

1. Marco exterior de rareza: Diamante / Oro / Blanco-Violeta.
2. Ventana central amplia para fotografía real de medio cuerpo.
3. Fondo interior azul marino metalizado.
4. Escudo del Real Madrid detrás del jugador, como marca de agua sutil (aprobado expresamente para Oro; aplicar a otros niveles solo si se confirma).
5. Bandera de nacionalidad en una esquina de la ventana de fotografía.
6. Zona inferior para número y nombre del jugador.
7. Mismo lienzo, proporción, área de fotografía, tipografía y jerarquía visual para los 50 cromos.

No inventar el dorsal histórico si no está verificado; si el jugador usó varios dorsales, acordar cuál mostrar.
